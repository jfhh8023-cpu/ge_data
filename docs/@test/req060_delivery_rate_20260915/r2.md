## 修订需求 v2

- 每个官方实际工作日8h；假期和普通周末0h；官方周末补班8h。重叠假期、周末只处理该日一次。
- 日历尚未保存或值班停用，也必须扣官方假期。值班未配置、换班、人员跳过不改变全员工作日。
- 手动停排是否代表公司休息、留职/长假是否减免应工作日，均为待确认业务边界；默认建议不把值班配置当考勤。
- 日历缺失不能伪装为“已校验40h”；建议仍显示分子，分母/交付率显示待核实。有有效旧快照时使用快照并提示版本及同步状态。
- 历史改为100%的旧需求进度展示保留为独立语义，不允许传播到交付率。

## 开发测试计划 v2

后端增加独立工作日解析与人员周容量计算，复用官方节假日快照数据，不修改值班调度服务行为。设计缺失日历和人员状态的可解释返回值。日期按北京时间、自然周周一至周日处理。
