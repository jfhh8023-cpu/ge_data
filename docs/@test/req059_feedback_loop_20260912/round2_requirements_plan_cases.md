# REQ-059 第2轮：交互与零值口径反哺

## 继承用例

继承 R1-API-001、R1-UI-001、R1-UI-002、R1-UI-003。

## 新增用例

| 编号 | 场景 | 验收 |
| --- | --- | --- |
| R2-UI-001 | 默认零值开关 | 仅显示有数据的需求方柱和总计柱 |
| R2-UI-002 | 关闭“隐藏零值” | 每个产品经理显示四类需求方柱和总计柱，零值不伪造数值 |
| R2-UI-003 | 点击产品经理名称 | 下方明细筛选到对应人员，提示文案同步 |
| R2-DATA-001 | 多需求方记录 | 需求方分配使用权重或均分，总计不重复累计 |

## 探索发现与设计修订

- 零值开关由共享状态驱动多个统计图；需要确认 AI产品展示开关切换后本图即时刷新且不改变数据。
- 产品经理筛选必须清空需求方筛选，避免两个筛选维度产生不可见交集。

## 反哺到第3轮

增加开关往返、筛选清除、总计与需求方分配可解释性检查。
