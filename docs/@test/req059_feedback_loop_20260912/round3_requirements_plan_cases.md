# REQ-059 第3轮：跨模块与边界反哺

## 继承用例

继承 R1-API-001、R1-UI-001、R1-UI-002、R1-UI-003、R2-UI-001、R2-UI-002、R2-UI-003、R2-DATA-001。

## 新增用例

| 编号 | 场景 | 验收 |
| --- | --- | --- |
| R3-REG-001 | 切换到部门展示再回到 AI产品展示 | 研发图和产品经理图数据维度不串线 |
| R3-REG-002 | 需求方目录动态返回 | 图例和颜色来自 API 目录，不依赖页面硬编码 |
| R3-EDGE-001 | 当前范围无产品记录 | 显示空状态，不渲染错误分组 |
| R3-EDGE-002 | 需求方零值 | 开关开启时隐藏零值柱，关闭时保留零值柱位 |
| R3-UI-001 | 1280 与 1920 宽度 | 页面不出现非预期横向滚动，姓名和柱组可识别 |

## 反哺结论

- 前端需要保持产品经理姓名作为唯一分组键，不能使用数组索引。
- 需求方目录需要按排序字段生成柱序，颜色直接使用目录颜色。
- 空数据判断应以产品记录集合为准，不能只判断目录是否存在。
