# 节假日误显排班回归计划

| 用例 | 范围 | 断言 |
|---|---|---|
| C24-01 | 官方快照 | 春节、劳动节、端午节、国庆节日期元数据准确 |
| C24-02 | 历史保护 | 生效日前旧预览不改写历史日志与轮换基准 |
| C24-03 | 真实调度 | 生效后国庆节无人员、无开始/结束事件 |
| C24-04 | 补班 | 2026 年 6 个官方补班日全部正常排班且有通知事件 |
| C24-05 | 页面日历 | 红色节假日格不显示姓名，补班格显示姓名 |
| C24-06 | 页面详情 | 停排日显示“整日停排 / 值班通知不生成” |
| C24-07 | 交互 | 首个修订生效日前左键不产生覆盖，停排日不能配置换班 |
| C24-08 | 质量门禁 | 前后端语法、前端构建、控制台和布局检查通过 |
| C24-09 | 展示隔离 | 生效日前补班使用只读投影，生效后结果与真实运行时一致 |
