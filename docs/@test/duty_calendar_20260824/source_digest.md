# 节假日误显排班复核来源摘要

- 需求来源：2026-08-24 用户截图反馈“有些节假日也被排班了，需要检查”。
- 追加需求：2026-08-24 用户明确“补班的日子要正常排班”。
- 截图样本：2026 年春节、劳动节、端午节日期格为红色法定节假日，但左上角仍出现人员姓名。
- 数据边界：只读取本地环境；不得向生产或真实 webhook 写数据。
- 已确认规则：年度日历首个修订生效日为 `2026-08-24`，历史执行记录不可回算或改写。

## 核心判定

1. 生效后的法定节假日必须 `whole_day_skipped=true`、最终人员为空、通知事件为空。
2. 官方补班日必须 `effective_skipped=false`，并按顺延序列生成最终人员与通知事件。
3. 生效日前旧模板可以作为运行时历史兼容数据保留，但不得与红色停排状态一起在日历格和详情区误显示为当前排班。
4. 生效日前官方补班日必须通过只读展示投影补齐人员；该投影不得进入自动通知和历史执行链路。
