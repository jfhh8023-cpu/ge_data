## 核心判定

1. 官方补班日不是停排日，必须进入正常排班序列。
2. 未发布的未来年度保持待同步，不预测、不生成伪节假日。
3. 后发官方修订公告覆盖年度原通知中的冲突日期。
4. 右键仅选择日期；左键保留停排切换。
5. `start_only` 即使保留历史结束文案，也不能生成、显示或发送结束提醒。
