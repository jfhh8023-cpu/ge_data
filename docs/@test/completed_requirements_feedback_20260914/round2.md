## 探索结论

- 当前实现以 `staffName` 作为 Vue key、Map key 和筛选值；如果系统允许同名人员，CHART-01 将暴露数据合并问题。应改用稳定 staff_id，展示姓名仍可重复。
- 需求方均摊和总计口径可独立校验，不能只看柱数量。
- 第3轮增加版本页导出、分页、需求方目录引用删除保护和 webhook 错误透传。
