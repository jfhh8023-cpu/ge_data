# 第3轮：系统边界与运行链路反哺

## 继承

继承第1轮全部数据口径和第2轮 CHART-01~04、UI-01；CHART-01 已确认同名 ID 合并缺陷，修复继续延后到第4轮。

## 新增用例

| ID | 场景 | 预期 |
| --- | --- | --- |
| SOURCE-01 | 服务端需求方分配聚合 | 70/30 权重为7/3，总计原始10 |
| SOURCE-02 | 需求方目录 | 默认四项、名称规范化、动态目录 |

| VERSION-01 | 版本号/人员/岗位去重与当前页导出 | 去重结果和导出范围一致 |
| DUTY-01 | 节假日/补班/换班预览 | 规则、当天人员和通知口径一致 |

## 探索结论

- 服务端目录分配总计口径正确，但需求方引用删除需要覆盖 ID 和名称两种历史存储形式。
- 前端契约检查能确认选项存在，不能替代真实弹窗/API链路；第4轮必须区分通过、静态覆盖和未能触发。
- 旧运行脚本包含本地写库夹具，需逐个执行并确认清理；真实 webhook、生产调度和国家节假日远程同步不在本次权限范围内。
