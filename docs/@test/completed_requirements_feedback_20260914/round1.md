# 第1轮：需求/设计与数据口径

## 计划

从真实实现读取统计公式，分别执行前端与后端同一输入的计算；校验版本空值定义与历史周边界。先收集问题，第四轮冻结后统一修复。

## 用例

| ID | 前置/动作 | 预期 |
| --- | --- | --- |
| DATA-01 | 10h100%、2h50% | 前后端均91.67% |
| DATA-02 | 10h100%、10h null | 100%；有效10h、未填1 |
| DATA-03 | 10h100%、10h空字符串/空白 | 100%；未填不入分母 |
| DATA-04 | 10h100%、10h0% | 50%；0是合法进度 |
| DATA-05 | 全部空进度/零工时 | null，不伪造0 |
| DATA-06 | 进度-10/110/布尔值 | 不参与合法进度计算 |
| VER-01 | 空/空白/-/v1 | 前三者无版本，v1普通版本 |
| HIST-01 | 上周/本周/未来周 | 仅已结束周覆盖为100，不写原记录 |
