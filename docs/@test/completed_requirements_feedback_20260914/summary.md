# 已完成需求闭环总结

## 执行范围

本次针对前序已完成的 AI 产品经理工时、需求方均摊、历史进度、版本分类、产品经理图表、分页、导出与值班/自动通知相关回归要求，执行了四轮“需求 -> 用例 -> 探索 -> 反哺 -> 修复 -> 复测”。实际全量 runner 共 18 个用例，18 个通过；子通知隔离回归另行执行并通过。

## 四轮反哺结果

1. 第1轮发现进度空值、空白和越界值被 `Number()` 转为 0 的统计缺陷；已统一归一化，非法值不参与加权分母并计入未填写。
2. 第2轮发现同名 AI 产品经理按姓名合并，导致不同人员柱状图和筛选冲突；已改为稳定人员 ID 分组，姓名只负责展示。
3. 第3轮发现分页/进度选项的契约校验表达式存在误报风险；已修正测试契约，并补充需求方目录、权重均摊与真实接口覆盖。
4. 第4轮发现 Playwright 的长连接加载等待和重复提示定位会造成测试误报；已改为业务节点就绪等待，并使用明确的最后一个筛选提示节点。
