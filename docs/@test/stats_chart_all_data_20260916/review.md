# 周期统计柱状图完整展示验收

日期：2026-09-16。范围：本地周期统计部门双图、产品单图、研发单图。状态：7 项定向检查通过。

## 实现

复用 `ProductHoursChart.vue`，固定 18px 同宽柱，根据容器宽度和系列数自动分行，较多行时缩小绘图区高度。每个图内共用数值尺度，完整显示组名、标签、图例，保留隐藏零值与人员点击行为。没有通过隐藏超宽内容来消除滚动条。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 1600px 部门双图 | 研发 9 组按 5+4 分行，产品 5 人按 3+2 分行；全部组与数值可见，柱宽均 18px |
| 关闭隐藏零值 | 研发 45、产品 25 个系列位置均保留 |
| 390px 部门图 | 全部人员按宽度分行，图表及页面无横向溢出 |
| 产品单图 | 5 名人员完整呈现 |
| 产品人员点击 | 原筛选交互保留 |
| 研发单图 | 全部 9 组可见，原明细入口保留 |
| 额外 14 人窄屏边界 | 数据完整分行展示，无裁剪 |

桌面左图实测 `clientWidth=919`、`scrollWidth=919`，组件高 448px；栏位相等的柱宽为 18px。全部数据无需左右拖动，纵向行数取决于宽度与人数，不将“全部显示”解释为所有屏幕都必须一个首屏装下。

Vue SFC 编译通过，主代理最终前端构建和差异检查通过。浏览器 `pageerror=[]`，业务写请求为空；测试没有写业务数据。主代理已人工查看桌面部门双图截图。
