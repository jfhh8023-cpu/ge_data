# REQ-055 第3轮用例反哺

| 来源用例 | 发现 | 修订 |
|---|---|---|
| R3-D-003 | 产品人员总进度与需求方分摊进度可能重复相加 | 明确人员原始进度只按原始工时；需求方进度只在需求方分组页展示，不能再汇总相加 |
| R3-D-006 | 需求去重键缺少来源和人员 | 冻结复合键并在公式步骤、导出说明和接口元数据中返回 |
| R3-D-004/R3-E-002 | 改名后历史报告显示存在冲突 | 快照按 revision 冻结；实时统计显示当前名称，并同时返回旧显示名称（如存在） |
| R3-C-001 | 目录修改与统计缓存可能短暂不一致 | revision 写入后强制失效目录和统计缓存；请求携带 revision |
| R3-E-001 | 显示舍入可能导致柱图和卡片相差 0.01 | 原始数值在 API 保留精度，前端只在展示层舍入并显示差异容忍说明 |

## 第4轮门禁

覆盖浏览器全流程、权限、导入导出、刷新返回、失败重试、XSS/公式注入和回滚；任何关键失败都不冻结。
