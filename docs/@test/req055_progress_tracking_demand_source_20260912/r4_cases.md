# REQ-055 第4轮冻结候选测试用例

| 编号 | 类别 | 场景 | 预期 |
|---|---|---|---|
| R4-E-001 | 端到端 | 填报产品记录→统计卡片→需求方图→详情→下载 | 记录、工时、进度、来源和导出一致 |
| R4-E-002 | 端到端 | 研发记录与产品记录相同任务/版本 | 双图和双来源列表不串数据 |
| R4-E-003 | 端到端 | 卡片点击普通版本/无版本号/全部追踪 | 页签数据互斥，范围元数据正确 |
| R4-E-004 | 端到端 | 产品人员×需求方排序/奖牌/返回 | 姓名和需求方维度清晰，排序不丢筛选 |
| R4-E-005 | 端到端 | 部门双图 1280、1920、80%/125% | 无横向滚动，右图较窄但单柱与左图一致 |
| R4-P-001 | 权限 | 普通用户访问目录写接口和他人导出 | 403；页面不因隐藏按钮绕过服务端 |
| R4-P-002 | 安全 | 需求标题/需求方名称含 HTML 和 Excel 公式 | 页面转义，导出以文本保存，不执行公式 |
| R4-P-003 | 安全 | 筛选参数注入、超大日期范围 | 参数化查询、校验和限流/分页生效 |
| R4-C-001 | 并发 | 两管理员同时改名/删除被引用项 | 一次成功，一次 revision 冲突；引用项删除 409 |
| R4-H-001 | 历史 | 旧记录无进度、旧目录名称、旧静态报告 | 空进度不进分母，旧快照名称不被静默改写 |
| R4-X-001 | 导出 | 当前范围/全部范围/进度明细下载 | 工作表带范围、筛选、revision、公式和生成时间 |
| R4-R-001 | 回滚 | 关闭 feature flag 或统计接口失败 | 旧入口可用，新数据不丢，用户看到明确错误 |
| R4-N-001 | 空态 | 没有产品记录、全为零工时、没有需求方图数据 | 空态清楚，无 NaN、无旧数据残留 |
