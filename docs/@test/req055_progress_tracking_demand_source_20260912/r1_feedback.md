# REQ-055 第1轮用例反哺

## 来源

上一轮：`r1_cases.md`，本轮根据基线用例做需求收敛。

| 来源用例 | 暴露问题 | 修订决定 |
|---|---|---|
| R1-F-002 | 普通版本/无版本号边界不够明确 | 普通版本为 trim 后非空且不等于 `-`；无版本号统一归一化 |
| R1-D-002 | “综合进度”可能被误解为任务数量平均 | 明确继续使用工时加权，空进度不进分母 |
| R1-U-001 | 产品需求方不是产品人员，不能走研发人员跳转 | 产品跳转使用产品来源和需求方筛选，不使用 PM 归属人 token |
| R1-C-002 | 仅正式记录引用不足以保护历史 | 将草稿、报告快照、导出元数据也纳入引用检查，待最终确认 |
| R1-X-001 | 下载可能只导出当前页面行 | 导出服务端重新按筛选查询并附带统计元数据 |

## 进入第2轮的新增门禁

- 必须定义字段默认值、空态、错误态、目录改名显示和页签默认项。
- 必须明确卡片哪些指标可点击以及权限行为。
