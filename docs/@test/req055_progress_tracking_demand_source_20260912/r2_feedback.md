# REQ-055 第2轮用例反哺

| 来源用例 | 发现 | 修订 |
|---|---|---|
| R2-U-002 | “全部”若直接查全库会越权 | 定义为当前权限和其他筛选不变，仅扩大时间范围 |
| R2-F-003 | 引用类型不能只查正式记录 | 需求方引用检查必须覆盖正式记录、草稿、快照和导出元数据，并在 API 事务中完成 |
| R2-S-001 | 只保存名称会使改名破坏旧数据 | 存稳定 catalog ID，名称作为版本化显示字段；兼容旧名称映射表 |
| R2-P-001 | 导出需要和前端页签一致 | 导出请求必须携带 scope、source、versionType 和所有筛选；服务端生成同口径结果 |
| R2-V-001 | 零工时会影响加权分母 | 有效工时定义为 `hours > 0` 且进度为数值；其他记录只展示不进分母 |

## 第3轮门禁

必须以最小数据集手算总工时、分配工时、去重需求数、版本数和加权进度，并验证 API、卡片、图表、列表和导出相同。
