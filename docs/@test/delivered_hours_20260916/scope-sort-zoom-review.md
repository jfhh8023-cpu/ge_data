# 范围一致、全量排序及独立缩放：验收结果

2026-09-16。结论：8 组定向用例最近结果全部 PASS。人工截图审查发现的 390px 年份/季度文字被压缩问题已修复并定向复测；最终双图原始工时合计已核对。

## 方法和范围

复现脚本：`node backend/scripts/verify_scope_sort_zoom_ui.js`；指定用例可用 `--case=SSZ-SCOPE,SSZ-SORT`。

- 真实本地只读 GET 验证当前季度、单周、全部历史及最终桌面图表。
- 47 条隔离浏览器记录、6 人（含未填）、两周及跨年历史，刻意使工时、需求名与创建日期顺序不同。双 PM 归属使用同一原始记录 ID；产品多需求方保留 70/30 权重。
- 主列表与弹窗的跨页顺序对照独立 comparator；不导入业务排序 helper 生成排序预期。所有 API 写请求拦截，运行期间没有业务写请求。
- 本轮不重跑此前大回归；纯排序的空白/数组、负数等边界由逻辑测试代理另行覆盖。未新增需求方筛选控件，因此没有虚构这类 UI 操作。

## 发现、失败与修复

1. **BUG，已修复**：首轮390px截图虽无页面横溢，但年/季选择器被flex压至约42px，仅剩箭头，当前值不可读。报告主代理后改为换行和固定年/季宽度；仅定向重测 SSZ-LAYOUT，修后120px/100px且页面宽390。
2. **SCRIPT，已修正**：首轮 SCOPE 用Esc关闭弹窗，刚操作的下拉框消耗了Esc；改为点击弹窗关闭按钮。此前所有数值断言已通过。
3. **SCRIPT，已修正**：人员筛选直接点击 Element 输入框被 placeholder 拦截；改点select容器。
4. **SCRIPT，已修正**：研发选项误写“AI研发（全部岗位）”，实际为“AI研发”；修正文案。
5. **运行环境/定位扰动**：后续 FILTER 定向运行时前端代码正保存更新，下拉选项变得不可见并从DOM移除；重新加载稳定页面后同用例通过，未改应用。原始失败保留，没有当成产品数据错误。

初次失败、复测和截图均保留于追加式 `scope-sort-zoom-results.jsonl` 和各批次目录。
