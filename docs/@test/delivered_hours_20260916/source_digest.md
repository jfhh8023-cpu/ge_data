# 已交付工时与交付率验证依据

日期：2026-09-16。

来源：本次用户需求，由主代理交接；既有 `work_hours_completion_20260916`、`stats_record_order_20260916`、`stats_chart_layout_20260916` 只读自动化与证据。

## 当前口径

- 统计卡片与分析弹窗的交付指标为“已交付工时”“交付率”。
- 有有效版本号的已填写工时直接计入已交付工时，不乘 `delivery_progress`。
- 交付率 = 已交付工时 ÷ 所属人员周期工作日容量；工作日每天8小时，同人同日不重复。
- 无版本工时保留记录，在无版本列表独立显示，不进入交付分子，也不显示无版本交付百分比。
- 历史周期不因日期已过去而强制100%；48h/40h保留120%。
- 删除“工时与交付进度怎么算”大说明区。简要说明置于弹窗头部卡片内，首屏尽早展示列表。
- 900px高桌面首屏能看到图表；弹窗打开后可看到表头和数据行；390px页面无横向溢出。
