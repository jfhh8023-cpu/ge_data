- 点击总工时打开部门需求进度明细；点击动态岗位只展示该岗位的1条记录。
- 26条有版本记录按创建时间倒序，前3条为32h、48h、最新0h记录。工时记录第2页6条；切换普通版本独立保持第1页20条，再切回仍是工时记录第2页。修改工时记录每页10条后，普通版本仍每页20条。选项为10/20/30/50/100/200/300。
