目标：验证存储隔离、统计口径、历史兼容和事务边界。  
来源：第3轮需求反哺文档。

| 编号 | 类型 | 场景 | 步骤/数据 | 预期 |

## 反哺发现

1. 需要明确 API 幂等键来源和重复提交的产品语义。
2. 需要确认综合进度中“无进度历史行”是否排除分母。
3. 需要验证所有报表的总工时是否默认合计两来源，还是默认非产品页签。
4. 需要把离职时间过滤、角色改名和数据快照加入最终端到端矩阵。

以上进入 R4 冻结。
