# REQ-051 部门展示双柱状图与统计卡片无横向滚动

日期：2026-09-12  
范围：仅本地开发环境，未推送远端，未发布生产。

## 实施内容

- `frontend/src/views/StatsPage.vue`：统计卡片取消最小宽度导致的横向滚动，改为容器内等分并对窄屏内容做溢出保护。
- `frontend/src/views/StatsPage.vue`：部门展示使用双列图表布局；左侧保留研发归属人图，右侧新增 AI产品需求方 Canvas 图，使用 4 个需求方维度和同一绘图风格。
- `docs/@demand/requirements.md`：归档 REQ-051 需求和统计口径。

## 验证计划

1. 在 1920px 和 1280px 宽度打开部门展示，确认卡片容器无横向滚动条。
2. 确认部门展示存在两个同水平图表卡片、两个 Canvas，右图包含四个需求方标签。
3. 切换零值开关和窗口尺寸，确认两个图表无运行时错误。
4. 执行前端构建和 `git diff --check`。

## 验证结果

- `npm run build`：通过；仅保留既有大 chunk 提示。
- Playwright 1920px、1280px：顶部卡片数量 10，卡片容器 `scrollWidth === clientWidth`，无横向滚动条。
- 部门展示：两个同水平图表卡片、两个 Canvas 均正常挂载；右图显示内部需求、客户需求、对外服务、其他需求 4 个维度。
- 零值开关和窗口重绘验证通过；浏览器无 `pageerror`。
- 证据截图：`docs/@development/req051-department-final.png`。

## REQ-053 增量

- 右侧 AI产品图柱宽改为参照左侧研发图的标准单柱宽度，避免 4 个需求方分组导致柱体横向放大。
- 证据截图待重新生成。

- 双图容器改为约 2.25:1 的横向比例，左侧研发图占主要宽度，右侧 4 个需求方图作为窄幅辅助图。
- `npm run build`：通过；仅保留既有大 chunk 提示。
