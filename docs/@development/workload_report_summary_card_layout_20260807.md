# 工时数据分析报告汇总卡片单行优化

## 基本信息

- 日期：2026-08-07
- 来源：用户截图及需求“截图所示红框内的5个卡片改成单行显示完整；不要换行”
- 涉及系统：DevTracker 工时数据分析报告
- 执行范围：仅本地开发环境，不推送远端，不发布生产

## 问题

工时数据分析报告总览页的汇总区域使用固定四列网格。系统增加“嵌入式软件工程师”后，汇总卡片数量变为五张，第五张卡片被折到第二行。

## 修改方案

1. 为总览汇总卡片组增加独立的 `overview-metric-grid` 样式，不修改下方四列洞察卡片布局。
2. 网格列数按“总工时卡片 + 当前启用研发角色数量”动态计算；当前为五列。
3. 每张卡片保留最小宽度，标题和说明文字强制单行显示。
4. 窄屏仍保持单行，通过横向滚动查看，禁止卡片折行或文字换行。

## 修改文件

- `backend/scripts/analyze_workload.js`

## 验收标准

- 当前五张汇总卡片在桌面报告中位于同一行。
- 五张卡片标题、数值和说明均完整显示且不换行。
- 下方洞察卡片仍保持原四列布局。
- 报告生成无错误，页面无控制台错误和失败请求。
