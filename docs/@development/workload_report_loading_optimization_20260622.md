# 工时分析报告加载速度优化记录

日期：2026-06-22

## 变更内容

- 将报告加载提示文案改为：正在加载中，请稍后...
- 优化工时数据分析报告周期切换加载方式：
  - 原方式：主报告内一次性内嵌所有周期的完整 HTML，页面打开时需要解析全部周期内容。
  - 新方式：主报告只内嵌当前页面内容和轻量周期目录；每个周期生成独立 HTML 文件，切换周期时直接跳转对应文件。
- 保留本地 `file://` 打开能力，也支持生产环境 `/devtracker/api/local-reports/` 静态访问。

## 涉及文件

- backend/scripts/analyze_workload.js

## 验证要求

- 重新生成本地报告后，确认 `devtracker_workload_all_latest.html` 文件体积明显下降。
- 使用浏览器打开本地报告，确认加载提示文案正确。
- 使用查询参数打开指定周报告，确认会跳转到周维度独立页面，且周维度仍展示柱状图。
- 生产发布前必须备份线上数据库，发布时继续使用 `deploy/deploy.py --skip-db`。
