# VOIP 独立角色测试源摘要

## 来源

- 用户需求：研发人员新增 `VOIP工程师`，赖香山和赵鲁鹏改为该角色，历史及后续数据在全系统独立显示和统计。
- 需求归档：`docs/@demand/voip_engineer_role_20260804.md`。
- 既有角色规约：`docs/@development/role_display_and_logic_audit_20260725.md`。
- 数据基线：两人共 87 条工时记录、773h；迁移必须事务化、幂等且总工时守恒。

## 流程矩阵

| 上游 | 处理 | 下游验证 |
| --- | --- | --- |
| 人员角色 | 新增/编辑/归一化/状态筛选 | 人员页、填写页、任务详情、通知名单 |
| 原始工时 | `WorkRecord + Staff.role` 聚合 | 部门、个人、AI产品经理、图表、分析弹窗 |
| 匹配组 | AI开发/VOIP/AI质量独立数组 | 需求工时页、手工编辑、自动保存、报表备份 |
| Excel | 模板、导入、导出 | VOIP 姓名与工时字段、旧模板兼容 |
| 离线分析 | 三角色聚合 | 总览、趋势、人员、需求、版本、关键词、质量 |
| 历史初始化 | 重建本地数据 | 目标人员不会回退为旧后端角色 |

## 假设与排除

- VOIP 沿用研发人员现有在职、离职、留职、长假规则；本次不修改人员状态逻辑。
- 在职 VOIP 的 0 工时展示规则与其他在职研发人员一致。
- 历史 `frontend/backend/test` 字段保留兼容，不作为新的 VOIP 存储位置。
- 不测试生产环境，不携带本地数据到生产，不提交、不推送、不发包。
