# REQ-058 本地开发记录

## 实现

- 在 `frontend/src/views/StatsPage.vue` 的版本统计行中收集记录所属任务的 `week_number`。
- 版本列表新增“周”列，格式化为 `W01`、`W32` 等自然周编号。
- 同一版本跨周时显示去重后的周列表，例如 `W27、W28、W29`。

## 验证

- `npm run build`：通过。
- Playwright 页面验证：版本页签存在“周”列数据，实际采集到 `W32`、`W27、W28、W29、W30、W31、W32、W33` 等值，页面异常 0 条。
- 本地页面：`http://127.0.0.1:5176/stats?admin=1`。
