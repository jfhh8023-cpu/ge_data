## 实施结果

### 1. 子通知

- 新增 `auto_task_child_notifications` 持久化模型及主规则 1:N 关系，支持 N 条子通知独立保存、启停、编辑和删除。
- 主 webhook 配置补充稳定 ID；子通知可选择全部、一个或多个当前主规则 webhook，后端校验目标归属。
- 新增周计划、月计划和精确到秒的调度计算；不存在的月日期直接跳过。
- 主规则仅在计划真实执行且主 webhook 全部成功后激活子通知；测试执行、测试发送、主规则保存和单纯启用均不激活。
- 子通知采用 `inactive -> pending -> sending -> sent/failed` 状态机和激活令牌。数据库条件更新用于发送抢占，同一激活轮次不重复发送。
- 主规则关闭、关闭通知或改为仅执行时，待发送子通知立即失活。
- 服务若在发送过程中中断，超过 60 秒仍处于 `sending` 的记录会结束为失败，本轮不自动重发，下一次主通知成功后重新激活。
- 设置页在“保存通知”下一行靠右增加“子通知”入口；弹窗包含规则说明、独立状态、倒计时、计划、目标、内容及增删改操作。

### 2. 值班规则定点生效

- `duty_config` 增加按 `effective_date` 排序的 `weekly_versions`，旧配置无需人工迁移。
- 固定/轮换互切时增加“本周起/下周起 + 周一至周日”组合选择，精确日期即时展示。
- 生效日前解析旧版本，生效日及以后解析新版本；概览、单日弹窗、后续三周、预览、倒计时和后端调度使用同一日期解析规则。
- 轮换锚点改为准确生效日，并只按实际排班星期推进人员顺序。
- 多次切换按日期保留版本；同一天重复保存替换同日版本，兼容字段始终同步为最新版本。
- 轮换人员序号继续按勾选顺序显示，确认蓝底白字。
