# 可配置研发角色本地实施方案

## 1. 最小改动策略

在保留现有表和兼容字段的前提下，增加一条通用角色链路：

1. `staff_roles` 成为显示名称、简称、颜色和顺序的唯一来源。
2. `staff.role` 保存稳定角色 key。
3. `match_groups.role_buckets` 保存任意角色的人员工时。
4. 旧角色列继续读写内置角色，确保旧页面、旧导入文件和回滚脚本可用。
5. 前端通过 Pinia 角色 store 加载角色定义，公共工具只保留兼容别名和兜底值。

该方案避免重建 `work_records`，也不删除历史列，控制数据迁移风险。

## 2. 后端任务

### 2.1 模型与迁移

- 新增 `StaffRole` 模型。
- `Staff.role` 模型改为字符串。
- `MatchGroup` 新增 `role_buckets` JSON。
- `RoleService` 实现建表、种子、缓存、验证、迁移、角色汇总和旧别名兼容。
- 启动顺序调整为先确保角色 schema，再注册可用角色缓存。

### 2.2 API

- 新增 `routes/roles.js`。
- `staff.js` 改为异步数据库角色校验，并支持姓名/手机/角色/状态查询参数。
- `stats.js` 和 `pm.js` 返回动态 `roleSummary` 与 `roleDefinitions`。
- `report.js` 读写 `role_buckets`，接受通用 `role_buckets` 请求；旧字段仍兼容。

### 2.3 匹配与报表服务

- `MatchService` 按 `normalizeStaffRole(record.staff.role)` 动态建桶。
- `ReportBackupService` 根据当前角色定义动态生成列。
- `WorkloadReportService` 的刷新签名加入 `staff_roles`。
- `analyze_workload.js` 查询角色定义并动态生成统计结构、图例、表格和文案。

### 2.4 Excel 与脚本

- 报表模板根据角色定义动态生成。
- 报表导入优先读取 `role_buckets` 或动态角色列，兼容既有 AI开发/VOIP/AI质量列。
- `init.sql` 增加角色表、嵌入式初始角色、字符串角色列和通用分桶字段。
- 旧业务导入脚本保留兼容，但新增写入通用分桶。

## 3. 前端任务

### 3.1 角色基础设施

- 新增 `stores/roles.js`，负责获取、新增、编辑和同步角色注册表。
- `utils/roles.js` 增加 `ROLE_EMBEDDED`，并支持动态完整名、简称、颜色、标签样式。
- 应用启动或相关页面挂载时加载角色定义。

### 3.2 团队人员

- 增加四项筛选和重置。
- 表格绑定筛选后的数据。
- 新增按钮改名。
- 新增角色配置弹窗。
- 新增/编辑人员角色选项改为动态数据。

### 3.3 需求工时统计

- Store 标准化 `role_buckets`。
- 页面按角色定义循环生成姓名列和工时列。
- 行编辑、人员选择、工时输入、自动保存和合计改为通用角色函数。
- Excel 导入导出使用动态角色列。

### 3.4 周期统计与聚焦

- 部门角色卡片、图例、柱状图、分析弹窗和导出改为动态角色循环。
- 研发聚焦“一起查看”按角色动态分组。
- PM 聚焦动态展示角色汇总。
- PM 柱状图使用 `chartDataWithHours`，过滤所有指标为 0 的项。

### 3.5 其他页面

- 任务详情、填写页、AI产品经理专属页统一使用动态角色显示函数。
- 角色标签不换行，窄空间使用简称。

## 4. 兼容与回滚

- 数据迁移只新增表/列并把 enum 放宽为 varchar，不删除业务数据。
- 内置角色继续同步到旧匹配组列。
- 旧 API 字段 `ai_developers/voip/ai_quality/frontend/backend/test_role` 保留。
- 回滚旧代码时，三个既有角色仍可从旧列读取；嵌入式和自定义角色只存在于 `role_buckets`，回滚前必须先备份。

## 5. 验证顺序

1. 只读基线：表行数、人员角色分布、工时记录数、总工时、匹配组总工时。
2. 启动本地后端，执行幂等 schema 迁移。
3. 验证四个默认角色和 staff 字符串列。
4. API 创建临时自定义角色、编辑角色、创建临时人员、写入临时报表行并验证统计。
5. 清理仅为测试创建的临时业务数据，保留角色功能代码和嵌入式内置角色。
6. 前端构建、浏览器桌面验证、控制台检查、截图归档。
7. 离线报告再生成并检查嵌入式/动态角色文本和数据。
8. 对比迁移前后核心数据守恒，确认没有远端与生产动作。
