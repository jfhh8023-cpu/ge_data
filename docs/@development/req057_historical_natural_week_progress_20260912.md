# REQ-057 本地开发记录

## 实现

- 在 `backend/src/routes/stats.js` 增加自然周边界判定：任务结束日早于本周周一时视为历史自然周数据。
- 统计接口、进度详情接口、Excel 导出和研发/AI 产品展示数据统一应用展示层覆盖：`delivery_progress=100`、状态“已完成”。
- 不更新数据库原始记录；当前周和未来周期保留原始进度。

## 验证

- `node --check backend/src/routes/stats.js`：通过。
- 进度详情接口：697 条历史记录，697 条覆盖，异常覆盖 0 条，综合进度 100%。
- 周期统计接口：131 条记录全部正确覆盖，AI 产品经理记录覆盖 2 条。
- Playwright：统计卡片显示 100.00%，详情列表首 20 条均显示“已完成”，页面异常 0 条。
- 本地页面：`http://127.0.0.1:5176/stats?admin=1`。

## 数据安全

- 仅在 API 返回和统计计算层生成展示值，没有执行数据库 UPDATE。
