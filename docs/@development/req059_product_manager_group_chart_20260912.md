# REQ-059 AI产品展示按产品经理分组柱状图实施记录

## 需求

AI产品展示不再仅按需求方汇总。图表底部按 AI 产品经理分组，每位人员显示四类需求方数据和总计数据；零值柱由开关控制是否隐藏。

## 实施范围

- 文件：`frontend/src/views/StatsPage.vue`
- 从统一需求方目录读取名称、排序和颜色，不在页面内固定需求方选项。
- 按产品经理聚合记录；多选需求方按记录保存的权重分摊，未提供有效权重时均分。
- 总计柱使用记录原始工时，避免多选分摊导致总计重复或缩小。
- 默认开启“隐藏零值”；关闭后保留所有需求方柱和总计柱的柱位。
- 产品经理名称支持点击筛选下方明细，并清除需求方筛选，避免两个维度互相误导。

## 兼容性

- 部门展示中的研发归属人图和需求方图逻辑不变。
- 现有历史数据、空数据和动态需求方目录均可继续渲染。
- 本次仅修改前端展示和筛选逻辑，不修改生产数据、后端存储或生产环境。

## 验收口径

1. 横轴展示产品经理姓名。
2. 每个姓名下最多展示四类需求方柱和一个总计柱。
3. 默认隐藏零值柱，关闭开关后显示完整五柱集合。
4. 多选需求方的分配总和等于记录工时，总计柱等于原始记录工时汇总。
5. 点击姓名后，明细列表仅展示该产品经理数据。
