# 自然周快捷选择状态规则优化记录

日期：2026-06-28

## 触发需求

用户要求工时数据分析报告顶部周期粒度只保留 `全部 / 年度 / 季度 / 月份`，但 `全部` 等周期范围仍要显示按年度自然周计算的自然周按钮；左右 `《` / `》` 需要可点击并每次移动 2 个按钮；自然周按钮按任务与统计数据状态区分禁用、蓝边禁用和可点击状态，并且仅当前有效周显示淡蓝色底部三角。

## 需求归档

- 已在 `docs/@demand/requirements.md` 新增 `REQ-040`。
- `REQ-040` 约束周期统计页与本地工时数据分析报告的自然周快捷选择行为一致。

## 涉及文件

- `backend/scripts/analyze_workload.js`
- `backend/src/routes/stats.js`
- `frontend/src/views/StatsPage.vue`
- `docs/@demand/requirements.md`

## 实现内容

- 工时数据分析报告“粒度”下拉移除 `周`，只保留 `全部`、`年度`、`季度`、`月份`。
- 报告生成时新增自然周元数据，按年度自然周生成 `ready`、`empty`、`no-task` 三种状态。
- `no-task`：未生成收集任务，灰色禁用。
- `empty`：已生成收集任务但无统计数据，蓝色边框禁用。
- `ready`：有统计数据，正常显示并可点击进入对应周报告。
- 报告页与统计页的 `《` / `》` 改为按钮，每次向对应方向移动 2 个自然周。
- 当前有效周或当前进入的周仅显示一个淡蓝色底部三角，其他按钮不显示三角。
- `/api/stats` 返回任务列表时补充 `record_count`，让统计页可以准确识别“有任务但无数据”。
- 追加优化：统计页左右移动按钮从 `《` / `》` 文字符号改为 Element Plus 图标按钮，采用轻量边框和悬浮反馈。
- 追加优化：统计页自然周条改为响应式固定轨道，按可用宽度动态减少可见周按钮数，避免筛选行撑宽页面、影响 Tab 和图表区域。
- 追加优化：工时数据分析报告自然周左右移动按钮同步改为 SVG 图标按钮。
