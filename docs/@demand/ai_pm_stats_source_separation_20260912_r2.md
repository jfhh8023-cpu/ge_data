# REQ-049 第2轮反哺：数据来源与历史兼容

状态：待用户确认；本轮只修正文档和用例，不改代码。

## R1 用例反馈

- 研发图表和产品图表的横轴语义不同，不能只靠增加一个系列解决。
- 产品需求方允许多选时，若每个柱子都累加原始工时，柱子合计会大于总工时。
- 历史空进度必须与真实 0% 区分，页面统一显示 `-`。

## R2 反哺决策

1. 部门全观保留研发主图，产品数据使用同页独立补充图，不混用横轴。
2. 顶部增加 AI产品经理工时和 AI研发人员工时两个清晰页签；产品页签完整复刻部门全观的数据交互。
3. 需求方多选的维度图使用均摊，原始明细和总卡片只计一次。
4. DTO 必须带来源类型，不用字段是否为空推断来源。
5. 历史无进度显示 `-`；真实 0% 显示 `0%`。

## R2 验收补充

- 同一筛选范围内，部门研发主图与 AI研发人员工时页签的每个工程岗位工时一致。
- 产品卡片总工时与产品明细原始工时一致；需求方柱子均摊后合计一致。
- 产品数据不会出现在研发归属人图；研发数据不会出现在需求方图。
