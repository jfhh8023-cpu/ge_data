# VOIP 工程师独立角色需求

## 1. 变更背景

研发人员新增独立岗位 `VOIP工程师`。赖香山、赵鲁鹏由 `AI开发工程师` 调整为 `VOIP工程师`，两人的既有工时记录、后续录入和所有统计结果均须按 VOIP 独立展示，不能继续并入 AI开发。

本次仅修改本地开发环境，不提交、不推送、不发包、不发布生产。

## 2. 统一角色口径

| 角色键 | 完整名称 | 紧凑名称 | 统计颜色 |
| --- | --- | --- | --- |
| `ai_dev` | AI开发工程师 | AI开发 | 蓝色 |
| `voip` | VOIP工程师 | VOIP | 绿色 |
| `ai_quality` | AI质量工程师 | AI质量 | 橙色 |

历史角色 `frontend`、`backend` 继续兼容并归入 `ai_dev`；历史角色 `test` 继续兼容并归入 `ai_quality`。`voip` 必须独立归类，任何默认逻辑不得将其回退为 `ai_dev`。

## 3. 功能范围

1. 团队人员：新增、编辑、交接、状态管理和角色标签支持 VOIP工程师。
2. 工时填写：VOIP 人员专属链接、任务详情和工时记录显示 VOIP工程师。
3. 需求工时统计：新增 VOIP 姓名与工时列，支持手工行编辑、自动保存、排序、导入、导出和模板下载。
4. 周期统计：部门总览、人员投入、AI产品经理聚焦、图表、明细弹窗和分析表单独统计 VOIP。
5. 离线工时分析报告：总览、趋势、产品经理、人员、需求、版本、关键词和数据质量模块均按三类研发岗位展示。
6. 在职零工时：VOIP 与其他在职角色口径一致，在需要展示全体在职人员的统计中保留 0 工时人员。
7. 离职规则：沿用现有离职时间范围规则，不因新增角色改变。

## 4. 本地数据迁移

精确按姓名迁移 `赖香山`、`赵鲁鹏`：

- `staff.role` 更新为 `voip`。
- `work_records` 原始记录不改动。
- `match_groups.frontend/backend/test_role` 中两人的角色条目迁移到 `match_groups.voip`，工时逐条守恒。
- 迁移前备份本地数据库；迁移脚本必须幂等，且目标人员缺失或重名时拒绝执行。

基线：两人共 87 条工时记录、773 小时；历史匹配组中共 87 个角色条目。

## 5. 验收标准

1. 人员接口及团队人员页中，两人角色均为 VOIP工程师。
2. 新增/编辑人员时可选择 VOIP工程师，后端拒绝未知角色。
3. 需求工时统计中的两人只出现在 VOIP 列，不出现在 AI开发或 AI质量列；总工时迁移前后相等。
4. 部门、个人、产品经理及离线分析报表均出现独立 VOIP 指标、图例、表头和数据。
5. Excel 导入导出与模板包含 `VOIP工程师姓名`、`VOIP工程师工时`。
6. 完整名称在空间足够时显示；紧凑图表使用 VOIP，所有角色标签不换行。
7. 前后端构建、API 回归和关键页面浏览器回归通过，无控制台错误。
8. Git 仅产生本地未提交改动，不存在远端推送或生产发布动作。
