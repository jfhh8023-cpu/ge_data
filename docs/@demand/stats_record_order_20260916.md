# REQ-061 周期统计记录排序与完成状态

日期：2026-09-16。依据：用户要求“周期统计和卡片内的工时记录，进度记录要根据创建时间倒序；已完成的进度/状态，要有绿色背景”。

## 规则与验收

- 工时及交付进度记录默认按记录 `created_at` 倒序，不使用工时大小、进度高低、修改时间或任务日期代替。
- 同需求多条记录的进度、工时汇总行按组内最新创建时间倒序；相同时间保持稳定，缺失或无效时间排末尾。
- 保留产品经理归属分组及合计，组内记录按创建时间倒序；保留手动切换工时排序。周期标题仍按原有业务周期排列。
- 覆盖部门、产品、研发明细，个人及归属卡片，工时分析弹窗、普通/无版本号及需求进度、全部追踪、进度弹窗与相关导出。补齐产品查看页及填写页已保存历史卡片，正在填写的表单不重排。
- 已完成的交付进度与状态使用绿色背景。工时完成度达到 100% 使用绿色底色，超过 100% 仍显示实际比例与超额提示，两种指标的计算口径沿用 REQ-060。
- 原始和汇总进度表分别展示“创建时间”“最新创建时间”，帮助核对顺序。

详细实施与验证记录见 `../@development/stats_record_order_20260916.md`。
