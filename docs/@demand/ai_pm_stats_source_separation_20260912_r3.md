# REQ-049 第3轮反哺：交互、跳转与统计一致性

状态：待用户确认；本轮只修正文档和用例，不改代码。

## R2 用例反馈

- 单独页签不能只换标题，必须具备卡片、图表、列表、筛选和点击分析的完整链路。
- 部门全观同时显示来源数据时，需要让用户一眼看到研发数据和产品数据的边界。
- 图表点击、卡片点击、底部列表点击必须传递同一时间范围和来源过滤条件。

## R3 反哺决策

1. 每个来源页签都有同样的四类能力：概览卡片、来源图表、明细列表、分析弹窗。
2. 部门全观的产品补充图标题明确写“按需求方”，研发图标题明确写“按AI产品经理归属人”。
3. 所有进度值使用统一显示函数：真实值显示百分比，历史空值显示 `-`。
4. 详情页必须显示“来源”和“需求方/归属人”对应字段，禁止把两个字段合并成一个模糊列名。

## R3 验收补充

- 点击产品卡片只看到产品记录；点击研发卡片只看到研发记录。
- 点击产品柱子只筛选需求方；点击研发柱子只筛选归属人。
- 切换年份、季度、自然周后，三个页签的卡片、图表、列表同步刷新。
