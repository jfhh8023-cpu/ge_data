# 工时数据分析报告版本筛选与 Excel 导出需求

日期：2026-09-08  
需求编号：REQ-047  
状态：开发中，仅本地验证，不自动发布生产

## 1. 用户需求

工时数据分析报告的“版本”页需要支持：

1. 按人员筛选；
2. 按岗位筛选；
3. 按版本号筛选；
4. 筛选值去重；
5. 按当前页面筛选结果导出 Excel。

## 2. 当前系统调查结论

- 报告不是 Vue 路由页面，而是 `backend/scripts/analyze_workload.js` 生成的独立 HTML，由 `/api/local-reports/workload-analysis/:fileName` 提供。
- 当前版本页只有静态的版本聚合表和图表，页面脚本只注入摘要，无法在浏览器端取得完整人员明细。
- 后端已经依赖 `xlsx`，但现有 Excel 路由主要负责业务页面模板和上传存档，没有版本报告专用导出接口。
- 报告生成器已经按离职人员、动态岗位和当前报告周期完成数据过滤，新增功能必须复用该报告快照，不能另造统计口径。

## 3. 页面方案

### 3.1 版本页新增区域

位置：版本页现有图表上方，版本汇总表下方保留现有排序能力。

| 区域 | 内容 |
| --- | --- |
| 筛选栏 | 人员、岗位、版本号三个原生下拉框；默认“全部” |
| 操作 | `重置筛选`、`导出 Excel` |
| 状态 | 当前匹配记录数、版本数、组合数、总工时，以及去重口径 |
| 图表 | 版本投入 Top 16、版本工时占比随筛选实时刷新 |
| 汇总表 | 版本号一行一条，按版本号去重 |
| 组合表 | 人员 + 岗位 + 版本号一行一条，按三项组合去重 |

筛选选项均由当前报告记录动态生成，不硬编码人员、岗位或版本号。

### 3.2 导出工作簿

导出文件名：`工时数据分析报告_版本_<当前范围>_<时间戳>.xlsx`。

| 工作表 | 内容 |
| --- | --- |
| 导出说明 | 报告范围、生成时间、筛选条件、记录数、版本数、组合数、总工时、去重说明 |
| 版本汇总 | 与页面版本汇总表一致，版本号一行一条 |
| 人员岗位版本 | 与页面组合汇总表一致，三项组合一行一条 |
| 筛选来源记录 | 当前筛选命中的每条原始报告记录，便于追溯，不合并合法重复记录 |

## 4. 数据与去重口径

- 人员筛选键：报告记录的 `staff` 原始姓名；同名记录只产生一个筛选选项。
- 岗位筛选键：报告记录的规范化 `role`；显示使用当前报告 `roleDefinitions` 的全称。
- 版本筛选键：报告记录的 `version`；空版本统一为 `未填版本`，同一版本号只产生一个选项。
- 版本汇总键：`version`。
- 人员岗位版本汇总键：`staff + role + version`。
- 合并汇总只用于页面汇总和对应工作表；“筛选来源记录”保留每条原始记录，避免把合法的多周期、多需求记录误合并。
- 工时、记录数、需求数、人员数和周期数均从当前报告快照计算；筛选无结果时所有合计为零。
- 离职人员的既有历史数据仍遵循报告原有时间口径；本需求不改变离职过滤逻辑。

## 5. 接口方案

### `POST /api/local-reports/workload-analysis/export`

请求：

```json
{
  "reportFile": "devtracker_workload_period_quarter_2026-Q3_latest.html",
  "filters": {
    "staff": ["张三"],
    "roles": ["frontend"],
    "versions": ["v4.864.0"]
  }
}
```

约束：

- `reportFile` 只允许报告目录下、以 `devtracker_workload_` 开头的 `.html` 或 `.json` 文件名。
- 服务端读取对应 JSON 快照并复用其中的 `records`、`roleDefinitions` 和范围信息。
- 接口只生成内存中的 Excel Buffer 并返回，不写入 `work_records`、报告数据或业务配置。
- 响应类型为 `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`。

## 6. 验收矩阵

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| V-01 | 默认打开版本页 | 三个筛选框为全部，图表和版本汇总与原报告一致 |
| V-02 | 人员筛选 | 只显示该人员命中的版本与组合，统计工时同步变化 |
| V-03 | 岗位筛选 | 只显示该岗位记录，岗位名称来自动态角色定义 |
| V-04 | 版本筛选 | 只显示精确匹配的版本号，空版本可选“未填版本” |
| V-05 | 多条件组合 | 三个条件同时生效，旧图表和表格结果被完全替换 |
| V-06 | 去重检查 | 选项无重复；版本表按版本一行；组合表按人员+岗位+版本一行 |
| V-07 | 空结果 | 图表、表格显示无数据，统计值为 0，不残留上一次结果 |
| V-08 | 导出检查 | Excel 下载成功，四个工作表存在，内容与当前筛选状态一致 |
| V-09 | 来源追溯 | 合法重复来源记录仍在“筛选来源记录”中，工时不丢失 |
| V-10 | 周期切换 | 切换年/季度/月/周报告后，筛选选项和导出范围随新快照更新 |
| V-11 | 接口安全 | 非法文件名返回 400/404；导出请求不改变数据库行数 |
| V-12 | 回归 | 现有报告生成、角色动态显示、离职人员过滤和周期快捷切换继续通过 |
