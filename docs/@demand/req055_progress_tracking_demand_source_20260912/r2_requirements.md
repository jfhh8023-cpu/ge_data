# REQ-055 第2轮需求修订

状态：`REVIEW_REQUIRED`。

## 相对第1轮的修订

- 详情弹窗默认进入“总览”，默认数据为当前范围；页签标题明确显示“普通版本（有版本号）”“无版本号版本”。
- “全部追踪和进度”取消时间范围限制，但保留当前用户可见的人员、岗位、来源和权限筛选，并显示“当前范围 / 全部范围”的时间边界。
- 卡片所有可点击指标采用按钮语义和 hover 提示；无数据显示空态，不打开旧数据。
- 综合进度明细支持从卡片、总览摘要、版本页签和产品页卡片进入，弹窗只读，下载参数绑定当前过滤条件。
- 需求方配置字段：名称必填 2～30 字、名称规范化后唯一、颜色为 `#RRGGBB`、排序为非负整数、启用开关；停用项不出现在新填报下拉，历史仍可读。
- 已引用项点击删除先显示引用计数和影响范围，二次确认后接口仍返回 409；改名保存后稳定 ID 和历史记录不变。
- 产品图点击需求方只更新产品详情筛选，研发图点击人员只更新研发归属人筛选；不得互相转换维度。

## 交互/字段验收

新目录、重名、空名、超长名、非法颜色、停用、新增产品记录、导入旧需求方、零工时和空进度均有明确错误或空态。
