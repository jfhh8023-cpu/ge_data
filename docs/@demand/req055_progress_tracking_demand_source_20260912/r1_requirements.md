# REQ-055 第1轮需求基线

状态：`REVIEW_REQUIRED`，仅文档阶段，未修改业务代码。

## 目标

让周期统计中的工时卡片、版本进度、AI产品经理需求方、部门双图和详情导出使用可追溯的统一数据口径，并允许管理员维护需求方目录。

## 基线范围

1. 所有工时卡片可点击进入详情弹窗；弹窗至少有总览、全部追踪和进度、普通版本、无版本号版本。
2. 综合进度按有效工时加权，进度为空不进入分母；详情可查看明细并下载。
3. AI产品展示以产品人员和需求方双维度展示，需求方柱子可跳转。
4. 部门展示保持研发归属人图和产品需求方图并列，研发图宽、产品图窄，单柱宽统一。
5. 角色配置中维护需求方目录，新增、改名全局生效，已引用项不可删除。
6. 研发工时表和产品工时表独立存储，跨来源响应必须保留 `source_type`。

## 初步数据流

填报/导入 → 独立来源表 → 统计快照 API → 卡片/图表/列表/详情 → Excel 导出；需求方目录贯穿输入、存储、统计和展示。

## 初步未决项

- 全部数据是否仅取消时间范围、保留其他筛选。
- 需求方被哪些对象引用时阻止删除。
- 普通版本去重键和无版本号需求的唯一键。
- 静态历史报告是否按快照名称冻结。
