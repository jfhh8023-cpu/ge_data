# REQ-055 第4轮冻结候选需求

状态：`REVIEW_REQUIRED`，待用户确认后方可开发。

## 冻结候选

1. 当前范围和全部范围为两个明确的只读统计范围，全部范围仅扩大时间边界，不扩大权限或其他筛选。
2. 研发与产品来源独立存储、独立统计；跨来源仅通过带来源类型的只读 DTO 展示。
3. 详情弹窗四页签、进度明细、可下载、产品卡片/需求方图点击跳转和部门双图均必须保留完整筛选上下文。
4. 需求方目录使用稳定 ID、名称、颜色、排序、启用状态和 revision；新增/改名全局生效；已引用不可删除；停用只影响新增数据。
5. 版本、无版本号、需求、人员、任务、需求方和进度均按复合键与来源隔离；加权公式和示例在所有计算入口有 Tips。
6. 历史空进度仍是空值展示，不进入分母；填写历史页已有的展示约定只作用于展示层，不得改变统计或导出原始值。
7. 旧静态报告按快照 revision 保留，新报告按当前目录生成；feature flag 可回滚，不做破坏性迁移。

## 明确不做

- 不将两张来源表合并。
- 不把需求方名称当作稳定主键。
- 不把全部历史数据自动混入当前卡片。
- 不以任务数量平均替代工时加权。
- 不在本阶段执行数据库迁移、生产数据读取、远端推送或生产发布。
