# REQ-049 开发与测试计划

状态：已确认并进入本地开发；禁止推送远端和生产发布。  
范围：AI产品经理工时来源隔离、研发/产品双视图、历史进度显示。

用户确认：研发归属人图与产品需求方图分离；产品多选默认均分且允许调整权重；产品页签显示产品人员姓名。

## 1. 开发顺序

### P1 数据契约

- 统一统计 DTO 增加 `source_type`、`demand_sources`、`product_manager_name`、`engineering_product_manager_names`。
- 保持 `work_records` 与 `product_manager_work_records` 独立读写。
- 增加需求方均摊视图 DTO，原始明细不变。

### P2 后端统计

- 研发查询只生成归属人维度数据。
- 产品查询只生成需求方维度数据。
- 部门总览合并来源时只合并卡片总量，不混合图表维度。
- 所有接口沿用离职过滤、历史可查和时间范围规则。

### P3 前端页面

- 历史列表进度显示函数：有值显示百分比，空值显示 `-`。
- 增加 AI产品经理工时和 AI研发人员工时页签。
- 部门全观增加产品需求方补充图。
- 抽取来源页签共用的卡片、图表、列表、分析弹窗和跳转组件。
- 对产品多选需求方图表显示均摊说明 Tooltip。

### P4 导出与回归

- 页面导出按当前页签和当前筛选快照导出。
- 产品导出包含需求方和来源；研发导出包含归属人和来源。
- 核对页面卡片、图表、列表、导出总工时守恒。

## 2. 数据守恒样例

研发记录：A 10h 归属张三；产品记录：B 10h 需求方“客户需求、内部需求”。

- 部门总工时：20h。
- 研发图：张三 10h；不显示 B。
- 产品需求方图：客户需求 5h、内部需求 5h；产品卡片 10h。
- AI研发人员工时页签：10h。
- AI产品经理工时页签：10h。

## 3. 回滚

- 关闭新增页签和产品补充图，保留原部门研发图。
- DTO 保留兼容字段，不删除原始来源记录。
- 前端回退时不改写历史进度和产品独立表。
