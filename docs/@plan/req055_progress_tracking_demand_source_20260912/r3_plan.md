# REQ-055 第3轮开发测试计划

## 数据方案

1. 需求方目录使用稳定 ID 和 revision；历史 JSON 名称读取时通过别名映射到 ID，未知项进入数据质量列表，不静默丢弃。
2. 统计服务统一构造原始记录 DTO、需求方分摊 DTO、进度 DTO 和范围元数据；前端不重新实现统计公式。
3. 详情下载复用统计服务，使用参数化查询和 Excel 字符串转义，避免公式注入。
4. 目录修改使用事务：唯一校验、引用检查、写入、revision 增长、缓存失效、审计日志必须同一操作；并发更新用 revision/更新时间防覆盖。
5. 以 feature flag 控制新版详情和目录；关闭时旧统计页仍可读取独立表，回滚不删除新数据。

## 计算核验

用上方 17h 算例校验卡片、产品人员、需求方图、普通版本/无版本号、进度弹窗和 Excel。检查分组小计与总计的允许差异只来自显示舍入。
