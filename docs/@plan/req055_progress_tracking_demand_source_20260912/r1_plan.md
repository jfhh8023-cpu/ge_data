# REQ-055 第1轮开发测试计划

## 模块拆解

| 模块 | 初步工作 | 验收证据 |
|---|---|---|
| 需求方目录 | 新增模型/API/权限/缓存；稳定 ID，名称唯一，引用阻断删除 | API 响应、审计日志、配置页截图 |
| 统计 API | 拆分当前范围与全部范围；独立研发/产品来源；返回口径元数据 | API JSON、SQL 查询结果 |
| 详情弹窗 | 统一卡片入口，四个版本/追踪页签，进度明细弹窗 | 浏览器流程截图 |
| 产品展示 | 人员×需求方柱图、卡片、列表、排序、跳转 | 多人员夹具与截图 |
| 部门双图 | 研发主图、产品辅图、固定单柱宽和响应式布局 | 1280/1920/缩放截图 |
| 导出 | 当前范围/全部范围/进度明细只读 Excel | 工作表和元数据核验 |

## 顺序与回滚

先目录读写和统计 DTO，再实现只读详情和导出，最后改前端图表。新增表/列采用扩展-收缩；任何统计异常可切回旧 DTO，旧研发表和旧产品表均不迁移合并。

## 风险

当前代码仍在 `stats.js` 固定四类需求方，`StatsPage.vue` 产品卡片并非全部可点击，且分析弹窗仅使用当前已加载记录。正式实现前必须解决这些差距。
