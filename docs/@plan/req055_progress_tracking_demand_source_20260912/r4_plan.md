# REQ-055 第4轮冻结候选开发测试计划

## 阶段

1. 先补目录模型、迁移兼容和权限测试；不删除旧字段。
2. 实现统计服务的 current/all scope、versionType、sourceType 和进度元数据。
3. 实现详情弹窗、分组页签、产品人员×需求方展示、跳转和只读下载。
4. 实现目录配置 UI、引用检查、改名/停用和缓存 revision。
5. 做前端桌面/缩放/窄屏回归，运行 API、浏览器和导出测试。

## 发布门禁

- 单元和 API 测试无 blocker；最小算例所有层一致。
- 权限、公式注入、XSS、SQL 参数、并发 revision 和回滚用例通过。
- 浏览器截图证明卡片、图表、弹窗、页签、列表和导出入口可读。
- 用户确认本轮三份冻结文档后，才允许创建代码任务；生产发布另行备份、审批和回滚评审。
