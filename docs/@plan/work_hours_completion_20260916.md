| 阶段 | 负责人 | 交付与验收 |
| --- | --- | --- |
| 1–3 需求/产品/计划 | 主代理 | 双指标、120%/超额20%、人员日期去重、空值与说明口径已确认并记录 |
| 4 后端 | 后端代理 | 独立工作日容量服务；stats/fill/tasks 只读结果与导出共享计算，不重写历史数据 |
| 5 前端 | 主代理 + 页面代理 | 统一工时组件/说明，统计各视图及填写/详情接入；保留交付指标并修复二次加权 |
| 6 审查 | 独立审查代理 | 检查范围过滤、分母重复、数据来源、错误处理；阻塞项修复后复查 |
| 7 安全检查 | 主代理/审查代理 | 本地静态与只读 API 检查；导出文本注入、无生产操作、无真实通知 |
| 8 验证 | 主代理 | 纯计算用例、API/Excel一致性、浏览器桌面/移动截图、前端构建 |

## 流程与用例矩阵

| 编号 | 输入/链路 | 预期 |
| --- | --- | --- |
| WH-01 | 单人5日周32/40/48小时 | 80%/100%/120%，最后超额20% |
| WH-02 | 两周标准32+40，实际24+40 | 64/72=88.89%，不是百分比平均 |
| WH-03 | 同人员同日、多个记录/任务/来源 | 基准去重；不同人员分别计基准 |
| WH-04 | 2人应填80，仅1人填40 | 50%，未填者保留分母 |
| WH-05 | 假期/补班/跨年/无日历 | 按实际快照；缺失明确估算；整周0基准不适用 |
| WH-06 | 历史100%交付、实际20/40 | 交付口径保留，工时完成度50% |
| WH-07 | 产品多需求方75/25、40h | 总40h，分项30/10h |
| WH-08 | 版本含缺进度、分组加权 | 直接以原始有效记录加权，样例9.09% |
| WH-09 | 统计当前/全部、岗位/来源筛选 → Excel | 人员、日期与分母同范围；页面导出一致 |
| WH-10 | 填写表单草稿 → 历史 → 详情 | 预览与正式记录区别明确，说明完整 |
| WH-11 | 桌面/移动、弹窗/键盘、120% | 无截断、口径可访问、无新浏览器错误 |
