# REQ-050 填写工时历史进度展示与工时分隔

日期：2026-09-12  
范围：仅本地开发环境，未推送远端，未发布生产。

## 触发问题

填写工时页面“我的历史”中，历史记录的进度展示不符合当前展示要求；进度符号与工时值相邻时，容易把分隔符误认为负号。

## 实施内容

- `frontend/src/views/FillPage.vue`：历史记录统一显示 `100%` 交付进度，仅改变展示，不修改接口提交和数据库原始值。
- `frontend/src/views/FillPage.vue`：进度和工时增加独立视觉样式及间距，保证文本边界清晰。

## 验证计划

1. 打开填写工时页面，展开“我的历史”，确认每条历史记录显示 `100%`。
2. 确认进度和工时之间有清晰间距，工时值不呈现为负数。
3. 确认本次仅为前端展示变更，不产生写接口请求。
4. 执行前端构建和浏览器检查。
